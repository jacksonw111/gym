# 普瑞健身 EMAS Serverless 完整迁移设计

## 目标

将小程序、网页后台、云函数、数据库、文件存储和定时任务全部从腾讯云开发切换到 EMAS Serverless。切换完成后，业务代码不再调用腾讯云函数、腾讯云数据库、腾讯云存储或 CloudBase 网页 SDK。

本次使用现有 EMAS 测试服务空间，从空数据库开始测试，不迁移腾讯云中的会员、预约、订单或其他测试数据。

## 已确认的决定

- 采用一次性完整切换，不保留双写或运行时回退。
- 保留现有小程序页面、网页后台界面和业务规则。
- 使用 EMAS 的微信授权身份作为用户唯一身份。
- 不迁移旧测试数据。
- 腾讯云资源暂不自动删除，但切换后不再接收业务流量。
- EMAS Client Secret 不提交到 Git。正式测试前重新生成，并通过本地忽略配置注入构建。

## 总体架构

### 小程序

小程序安装并初始化 EMAS Serverless SDK。应用启动时只完成 EMAS 的静默身份初始化，不请求头像、昵称或手机号。

用户仍然只在以下时机进入资料登录：

- 点击购买课包；
- 进入“我的”并主动点击登录。

头像上传改用 EMAS 云存储，业务调用改用 EMAS 云函数。现有 `GymApi` 接口继续作为页面与云服务之间的边界，新建 `EmasApi` 替代 `CloudApi`，页面不直接访问数据库。

### 云端业务

云端保留统一的业务动作协议，包括会员注册、购买、预约、取消、结课、反馈、申诉、教练排班和管理员操作。

云函数分为：

1. `gym-api`：通过 EMAS SDK 接收小程序请求。
2. `gym-admin-api`：通过 HTTP 接收网页后台请求，负责跨域、管理员登录和令牌验证。
3. `auto-complete-lessons`：按小时完成已经超过结束时间的课程。
4. `wechat-payment-notify`：预留真实微信支付回调；测试环境只允许明确的测试支付流程。

小程序函数和后台函数复用同一套业务规则，但入口和身份验证相互独立。

### 网页后台

React 后台构建后部署到 EMAS 静态网站托管。

由于 EMAS 客户端 SDK 不支持普通 Web/H5，后台不直接使用 EMAS SDK，而是通过 `fetch` 调用 `gym-admin-api` 的 HTTP 地址。HTTP 函数只允许配置的后台域名跨域访问，并继续使用管理员账号、密码和短期登录令牌。

## 数据设计

建立以下集合：

- `users`
- `coaches`
- `products`
- `memberships`
- `orders`
- `schedules`
- `lessons`
- `booking_locks`
- `appeals`
- `ledger`
- `admins`
- `admin_sessions`
- `operations`

所有集合的客户端读写权限都设为关闭。数据只允许通过云函数访问。

云存储只允许已授权用户写入自己的头像路径，文件读取用于小程序展示。

### 关键索引

- `users.emasUserId`：唯一。
- `booking_locks.slotKey`：唯一，格式为教练、日期和开始时间的组合。
- `operations.requestId`：唯一，阻止重复业务请求。
- `orders.requestId`：唯一。
- `ledger.operationKey`：唯一，阻止重复扣课或退款。
- `admin_sessions.tokenHash`：唯一。
- 课程、排班、申诉按常用查询字段建立复合索引。

## 预约与课时一致性

EMAS 公开数据库接口以单条记录原子更新为基础，因此不依赖跨集合事务。

每个会改变课时或课程状态的请求都携带唯一 `requestId`，并在 `operations` 中保存执行状态和最终结果。

### 创建预约

1. 校验会员身份、会员卡、教练绑定、时间范围和开放状态。
2. 创建唯一预约锁。锁已存在则返回“该时间已被预约”。
3. 以“剩余课时大于零”为条件扣减一节课。
4. 创建课程记录和课时流水。
5. 标记操作完成并返回课程。
6. 中途失败时按已完成步骤补偿，释放预约锁并退回已扣课时。

### 取消与退款

- 会员提前至少两小时取消：课程改为会员取消，释放预约锁并退回一节。
- 不足两小时：不允许会员直接取消，提示联系教练。
- 教练取消：由教练明确选择退回或不退回。
- 教练关闭开放时间：不改变已有预约。
- 申诉通过：管理员退回一节；同一申诉只能执行一次退款。

所有退款和扣减都使用唯一流水键，重复提交只返回第一次执行结果。

## 身份与授权

### 小程序用户

EMAS 初始化后取得稳定的 `userId`，保存为 `emasUserId`。这一步只建立服务身份，不代表会员已经提交资料。

会员资料仍需用户主动选择头像、昵称和手机号：

- 微信手机号授权成功时保存为已验证手机号；
- 模拟器或授权不可用时显示手动手机号输入；
- 手动手机号保存为未验证；
- 两种手机号入口不同时显示。

### 管理员

管理员密码保存为加盐摘要，不保存明文。登录成功后生成短期令牌，数据库只保存令牌摘要和到期时间。

后台 HTTP 请求必须同时通过：

- 允许的来源域名；
- 有效管理员令牌；
- 对应管理员权限；
- 业务输入校验。

## 配置与凭证

本地忽略配置包含：

- EMAS Space ID；
- EMAS Client Secret；
- EMAS API Endpoint；
- 文件上传和下载 Endpoint；
- 后台 HTTP 函数地址；
- 后台允许来源域名；
- 定时任务内部口令；
- 测试支付开关。

仓库只提交不含真实凭证的示例配置。测试与生产使用相同变量名，只更换服务空间和密钥，不改业务代码。

微信公众平台需要配置 EMAS 控制台提供的：

- `request` 合法域名；
- `uploadFile` 合法域名；
- `downloadFile` 合法域名。

## 初始数据

新数据库部署后只初始化：

- 一个可登录的管理员；
- 当前课包商品；
- 已确认的教练基础资料；
- 默认每天 10:00 至 21:00 的一小时时间段模板。

会员、会员卡、订单、课程、反馈和申诉从空数据开始。

初始化过程使用固定标识重复执行，不能生成重复管理员、商品或教练。

## 错误处理

- 未授权：引导重新初始化 EMAS 身份，不自动创建会员。
- 网络失败：保留 `requestId`，允许安全重试。
- 重复预约：返回明确的时间段已占用提示。
- 课时不足：不创建课程或预约锁。
- 部分写入失败：按操作状态执行补偿，再允许重试。
- 后台令牌失效：清除本地令牌并返回登录页。
- 云函数错误：记录请求编号、操作名和错误阶段，不记录手机号、密码或 Client Secret。

## 部署与切换顺序

1. 重新生成已暴露的 EMAS Client Secret。
2. 创建集合、权限和索引。
3. 部署云函数和定时任务。
4. 初始化管理员、课包和教练数据。
5. 部署后台静态网站并配置 HTTP 跨域白名单。
6. 在微信公众平台配置合法域名。
7. 构建小程序 npm 依赖并切换到 `EmasApi`。
8. 完成真实 EMAS 环境验收。
9. 删除项目中的腾讯运行依赖、配置和部署说明。
10. 确认无腾讯请求后停止腾讯测试环境的业务使用。

不在本次代码迁移中自动删除腾讯云控制台资源；如需释放资源，单独确认后执行。

## 测试与验收

### 自动测试

- EMAS 请求和响应适配。
- 用户身份映射。
- 头像上传结果转换。
- 预约并发和重复请求。
- 课时扣减、会员取消、教练取消、申诉退款。
- 关闭开放时间不影响已有预约。
- 管理员登录、令牌过期和跨域限制。
- 定时自动结课。
- 项目扫描确认不存在腾讯云运行调用。

### EMAS 测试环境

- 游客可看课包和教练，不创建会员。
- 点击购买或“我的”后完成头像、昵称、手机号资料登录。
- 微信手机号与手动手机号两条流程分别通过。
- 购买测试课包后绑定教练。
- 两个用户不能预约同一教练同一时间。
- 会员提前两小时取消自动退课。
- 教练取消可选择退课或不退课。
- 教练关闭时间不影响已有预约。
- 完成课程后可确认和提交可选反馈。
- 会员能查看历史课程并申诉。
- 管理员能判定申诉并只退回一次。
- 后台网页能登录、管理教练和会员。

### 完成标准

- 小程序和后台不再调用 `wx.cloud`、CloudBase SDK 或腾讯云函数。
- 所有自动测试通过。
- EMAS 云函数、数据库、存储、后台托管和定时任务均在测试空间运行。
- 核心验收流程全部使用真实 EMAS 数据完成。
- 切换测试与生产只需更换配置，不需要修改业务代码。

## 不包含的内容
